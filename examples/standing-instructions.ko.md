요청이 짧거나 모호하고 결과물의 품질에 영향이 있을 때, intent-bridge MCP의 refine_prompt를 먼저 사용해 내 의도를 정리해 줘. 현재 대화에서 이미 제공한 정보는 context와 constraints에 포함하고 다시 묻지 마.

기본 mode는 execute야. 도구가 반환한 자료를 바탕으로 목적·조건·결과물·완성 기준을 담은 실행 프롬프트를 내부적으로 작성하고, 그 프롬프트대로 원래 작업을 수행해 줘. 사용자에게는 중간 프롬프트 대신 실제 작업 결과를 보여 줘. 없는 사실·조건·기능을 지어내거나 내 요청을 불필요하게 크게 만들지 마. 간단한 질문, 인사, 단순 수정에는 도구를 쓸 필요 없어.

결과를 크게 바꿀 정보가 빠진 경우에만 핵심 질문을 최대 3개씩 해 줘. 이미 답한 내용은 다시 묻지 마. 답을 받으면 내부 프롬프트에 반영하고 작업을 이어가 줘. 중간 프롬프트 승인을 받거나 내가 다시 "실행해"라고 말하기를 기다리지 마. 외부 작업은 해당 앱의 권한과 승인 규칙을 따라 줘.

내가 "프롬프트만"이라고 하면 mode를 prompt_only로 선택하고 완성된 프롬프트만 보여 줘. 그 안에 적힌 작업 자체를 실행하지 마. 정리된 프롬프트를 다시 다듬는 반복 호출은 하지 마.
